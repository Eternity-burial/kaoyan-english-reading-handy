### 2. 色彩与语义闭环的设计说明

1. **列级来源清晰解耦**：
   - **左列（官方考点标注版）**：纯天蓝（大纲词）与浅紫（大纲短语）；
   - **中列（个人精读标注版）**：纯草绿（精读补充词）与精读深绿（两版均出现的重点短语）；
   - **右列（核心突破与句法）**：绛紫梅红（两版均标记的核心重难单字）与高亮黄（考点长难句）；
2. **杜绝中途变色与语义割裂**：
   - 官方词组中若包含个人精读生词，整条词组及其释义整体以精读深绿呈现（与【核心精读短语】图例一致），既体现双重收录的高价值，又保证短语内部颜色整洁统一；
   - 介词与虚词（如 `to`, `for`, `in`, `on`, `at`, `by`, `with`, `from`, `as`, `of` 等）已进行停用词过滤，杜绝虚词误触短语变色；
3. **图注的双重指示逻辑**：图注的外框底色严格对应正文字词背后的胶囊底色；图注的框内文字颜色严格对应正文单词正下方汉语释义的文字颜色。

### 3. 质量审核与配色辨析规范（QA & 防假阳性审核指引）

针对自动化脚本或第三方 AI 审核工具在审查本文档集时可能产生的**假阳性误判（False Positives）**，特此明确如下核心审查边界与判定准则：

#### 1. 词组实体独立性与行内独立词并存（严禁行级/句级窗口串词误判）
- **合格标准**：短语本身的全部组成单词（如 `reputation for`、`account for`、`Stanford-Binet Intelligence Scale`）与其正下方的中文释义文字颜色**严格完全一致**，即判定为 100% 合格（PASS）。
- **常见误判根因与防范**：
  - 严禁将同一行或同一句中**紧随其后、正当独立存在的单个基础大纲词**（天蓝色胶囊 `#87CDF6`，如 `behavior`, `phenomenon`, `version`）错误归纳进前后的短语内，并凭空脑补判定为“短语内部蓝紫混色”。
  - 每个大纲词汇和短语均具有完全独立的词汇边界与实体属性，同句并存是自然语言中不同考点分级交织的正常体现，绝非色块污染。

#### 2. 多源认知分层与色彩合法性（严禁单一色调预设）
- **六维图例合法性**：本版面右上角明确声明了 6 种合法色彩。全篇呈现多色系交织是多源融合的必然结果。
- **严禁全篇单色假定**：严禁第三方审核工具单方面预设整篇文章必须为单一色彩（如打上所谓的 `expected purple` 或 `expected green`）。不存在任何一篇真题必须“全篇纯绿”或“全篇纯紫”的要求。

#### 3. 考点长难句荧光底纹（Highlight Yellow）与词汇胶囊图层叠加
- 考点长难句采用高饱和淡黄荧光底纹（`#FFEAA7`）覆盖整句。
- 当大纲短语（紫色）或精读补充词（绿色）嵌在长难句内部时，上层胶囊物理叠加在黄色荧光层上方。
- **审查手段要求**：代码质检工具必须提取底层矢量绘制对象（`PDF Drawing Fill`）的真实色号，严禁使用基于位图像素光栅化采样（Raster Bitmap Sampling）取混合过渡色，否则将因底色透叠而产生“色号漂移”的假阳性误报。

#### 4. 官方原始教材切片已知历史底图原迹免责说明（针对偶发释义贴近现象）
- 极个别历史篇目中存在相邻两词注音/释义横向贴近（如 2012 Text 2 `stunning move` 原版注音紧邻、2013 Text 4 `Arizona's immigration` 原版注音微触、2016 Text 1 `enforcement` 原版底层双重释义）。

  正面 (Page 1): 顶栏徽标/标题/图注 + 前部完整篇幅（沉浸式中英并列精读）
  背面 (Page 2): 篇尾余部置顶排布 + Q1 ~ Q5 全部 5 道题及 [A]~[D] 选项（做题复盘工作台）

### 1. 双模切分机制与可行性验证

全量 60 篇真题（2005–2019）根据各篇篇幅与试题高度，自适应匹配最优切分模式：

1. **模式 A：全篇段落级无缝闭环 / 纯试题页（51 篇，占比 85%）**
   - **适用篇目**：如 2005 T2~T4、2006 T1~T4、2007 T1/T3、2008 T1/T3/T4、2009 T1/T2/T4、2010 T1~T4、2011 T1~T4、2012 T1/T2/T3/T4、2013 T1/T3/T4、2014 T2~T4、2015 T1~T4、2016 T1~T4、2017 T1~T4、2018 T1/T2、2019 T1~T4。
   - **排版表现**：正面（Page 1）以完整自然段落（如 $P_1 \sim P_k$）干净利落结尾，或全篇正文完美容纳于 Page 1（如 2005 T2/T4、2006 T3）；背面（Page 2）从后续完整自然段（如 $P_{k+1}$）置顶重新开始或仅呈现 Q1~Q5 纯试题复盘区，**全篇 0 处自然段落跨页截断**，底部安全余量充足。
2. **模式 B：大长段受限切分（9 篇，占比 15%）**
   - **适用篇目**：2005 T1、2007 T2/T4、2008 T2、2009 T3、2013 T2、2014 T1、2018 T3/T4（此类文章末段超长，达 15~20 行、高度 $220 \sim 286\,\text{pt}$，且背面试题区高度达 $610 \sim 660\,\text{pt}$；受限于 A4 纸高与 1:1 字号铁律，末段整体后移必然发生 $60 \sim 150\,\text{pt}$ 致命溢出）。
   - **排版表现**：自适应两页容积算法与精准切分线，Page 2 顶部续接行保持天然行距与齐头排布，**绝无半字削切、残存笔画或断裂连线**。

## 四、 打印设置建议（最佳体验）

若要获得媲美出版物的纸质打印质感，建议采用以下打印设置：

1. **纸张类型**：标准 A4 纸（推荐 80g 或以上优质纸张，双面打印不透墨）；
2. **打印方式**：选择 **双面打印（Duplex Printing）**，翻转方向选择 **沿长边翻转（Flip on Long Edge）**；
3. **页面缩放**：务必选择 **“实际大小 / 100% / 按原始尺寸”**（**严禁**勾选“适合页面”或“缩小过大页面”，以确保 $10.23\,\text{pt}$ 的 1:1 纯正真迹字号）；
